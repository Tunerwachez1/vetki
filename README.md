# Ветки — Android

Рабочая первая версия личного пространства: заметки с папками, визуальные деревья, календарь и напоминания. Интерфейс на русском и английском, тёмная тема. Данные хранятся локально, сетевых разрешений нет. При первом запуске пространство пустое: папки, заметки и холсты появляются только по действию пользователя.

## Язык интерфейса

В меню **⋮ → Язык / Language** доступны **Как в системе / System default**, **Русский** и **English**. Выбор сохраняется после перезапуска. На Android 13+ язык также можно выбрать в системных настройках приложения. Новые готовые шаблоны создаются на выбранном языке; существующие заметки, карточки и свои шаблоны не переводятся.

## Стек

Kotlin 2.1.21, Jetpack Compose / Material 3 (BOM 2025.06.01), ViewModel / StateFlow, Coroutines, Room 2.7.2, AlarmManager. AGP 8.11.1, Gradle 8.14.3, JDK 21. Android 8.0+ (minSdk 26), compile/targetSdk 35.

Версии зафиксированы для воспроизводимости. Это совместимый набор, а не заявление об использовании последних версий всех библиотек.

## Запуск

1. Открыть эту папку как проект в Android Studio, выбрать JDK 21.
2. Установить Android SDK Platform 35 и Build Tools 35.0.0.
3. Настроить `sdk.dir` в локальном `local.properties` либо `ANDROID_HOME`.
4. Выполнить `./gradlew :app:assembleDebug :core:test`.
5. Для тестов на подключённом телефоне: `./gradlew -Pqa=true :app:connectedDebugAndroidTest`. Пакет `dev.vetki.qa` устанавливается отдельно и не использует данные основного приложения.

Для release: `./gradlew :app:assembleRelease`. В этой ранней версии release подписывается локальным отладочным ключом. Перед публикацией нужен отдельный ключ подписи и процесс релиза.

## Возможности

- Создание, редактирование, переименование и перенос заметок и папок.
- Поиск по названиям с сохранением цепочки родительских папок.
- Автосохранение текста, Markdown как формат редактирования.
- Холсты: пустой, путешествие, работа, проект, принятие решения и свои шаблоны.
- Карточки, связи между ними, цвета статусов, отметка выполнения.
- Масштабирование и перемещение холста, устойчивое перемещение карточек долгим нажатием; карточки размещаются с зазором.
- Четыре точки соединения по центру сторон карточки: нажать точку, затем другую карточку. Независимые стрелки сохраняются; несколько связей не меняют иерархию дерева. Повторное соединение с той же целью меняет сторону выхода.
- Меню по нажатию на пустой холст: карточка, заметка, файл/изображение, веб-ссылка, группа, вставка; привязки и режим просмотра.
- Шаблон «Работа», сохранение своих шаблонов и встроенные советы по формулировкам.
- Просмотр холста вложенным списком, автоматическое выравнивание.
- Внутренний календарь: месяц, неделя, день и список задач выбранного дня.
- Раздел «Сегодня»: просроченные, сегодняшние и ближайшие напоминания.
- Напоминания из карточки и самостоятельные; ежедневное/еженедельное повторение.
- Мелодия «Спокойная музыка» (предоставленный пользователем MP3, около 10 секунд) встроена для напоминаний и будильников.
- Режим будильника: непрерывное воспроизведение MP3 по кругу, плавное нарастание за 60 секунд, кнопки остановки и откладывания.
- Для обычных уведомлений доступен повтор каждые 10 минут до подтверждения.
- Действия «Выполнено» / «Через 10 мин» из уведомления, переход к карточке.
- JSON-копия всей базы через системный выбор файла; проверка и восстановление копии с объединением по идентификаторам.

## Важные границы версии

Редактор пока показывает исходный Markdown. Нет облачной синхронизации, графа ссылок между заметками, интеграции с системными календарями, событий с длительностью и виджетов. Отдельное удаление стрелки пока не предусмотрено. Вложения до 8 МБ на файл, в резервной копии — до 20 МБ суммарно. Нет корзины и истории отмены: удаление требует подтверждения, перед ним можно экспортировать копию.

«Будильник» запускает службу foreground mediaPlayback, которая воспроизводит встроенную мелодию по кругу до остановки или откладывания. Громкость самого плеера за 60 секунд растёт с 12% до 100% относительно установленной в Android громкости будильника. Системная громкость не меняется. В приложении появляется экран остановки, а в постоянном уведомлении доступны те же действия. Одновременные будильники объединяются в очередь одного плеера.

Точное время требует разрешения на точные сигналы; без него интерфейс предупреждает о возможной задержке. Ограничения Android на запуск служб могут оставить только обычное уведомление, если запуск фонового воспроизведения запрещён системой. После принудительной остановки приложения в настройках Android нужно снова открыть приложение. Ограничения батареи Xiaomi также могут влиять на доставку. При входящем звонке или потере аудиофокуса воспроизведение приостанавливается по правилам Android.

## Структура

- `app` — экраны, навигация, тема, ViewModel, сборка компонентов.
- `i18n` — русские и английские ресурсы, выбор языка и локаль приложения.
- `core` — независимая от Android логика деревьев, повторений, модели холста.
- `data` — Room, схема и миграции, шаблоны, резервные копии.
- `canvas` — отрисовка, камера, жесты и доступность карточек.
- `reminders` — планирование, уведомления, действия и восстановление после перезагрузки.

Для первой версии используется явное создание компонентов вместо Hilt. Отдельные модули навигации, настроек и дизайн-системы появятся по мере роста проекта; пустых модулей и неиспользуемых библиотек здесь нет.
